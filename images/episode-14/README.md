1. **노크스 등장:** 검은 별 문장의 균열에서 긴 망토 같은 검은 그림자 정령 노크스가 나타난다. 모아와 보리 일행이 경계하는 장면.
2. **잊힌 기억:** 탑 벽에 어린 모아와 노크스가 검은 별 문장 앞에 서 있던 과거의 기억이 홀로그램처럼 떠오른다.
3. **루미의 손:** 수정 우리 안의 루미가 두려워하면서도 노크스에게 작은 손을 내민다. 따뜻한 금빛 별가루가 어둠에 닿는다.
4. **무너지는 검은 별:** 검은 균열이 문장을 깨뜨리고 바닥이 갈라진다. 루미의 별빛이 빨려 들어가며 모두가 위기를 맞는다.
5. **기억을 받아들인 모아:** 모아의 보랏빛 그림자와 노크스의 검은 그림자가 맞닿고, 어린 모아의 기억 조각이 별가루로 떠오른다.
6. **그림자의 등불:** 검은 별 문장 일부가 보랏빛 등불 모양 열쇠로 변한다. 모아가 감동한 표정으로 빛나는 열쇠를 바라본다.
7. **노크스의 선택:** 무너지는 탑에서 노크스가 거대한 그림자 보호막으로 보리 일행과 루미의 수정을 감싼다.
8. **별빛 우물 지도:** 그림자의 등불이 탑 벽에 구름 위 별빛 우물로 향하는 별 지도를 투영한다. 친구들이 새 목표를 바라본다.
