# AI 동물 웹툰 제작실

동물 친구들이 미스터리한 숲을 지키는 AI 웹툰 프로젝트입니다.

## 구성

- `stories/episode-10.md` — 10화 완결 스토리와 컷 구성
- `stories/episode-11-opening.md` — 11화 도입부
- `images/episode-10/` — 10화용 이미지 프롬프트와 10장의 SVG 씬 카드

## 제작 원칙

각 화의 이미지 프롬프트는 캐릭터 외형과 분위기를 일관되게 유지하도록 작성했습니다. SVG 씬 카드는 이미지 제작 전 장면·색감·구도를 확인하는 시각 가이드입니다.
